날짜별 4~6분 정도의 따뜻하고 경쾌한 여행 브이로그로 편집해줘.

- 날짜 카드 이후에는 실제 촬영 순서를 지켜줘.
- 출발, 이동, 도착, 주요 장소, 식사, 하루의 마무리가 보이게 해줘.
- 웃음, 감탄, 예상 밖의 상황처럼 재미있는 대화와 리액션을 우선해줘.
- 음식 자체가 잘 보이거나 먹는 반응이 살아 있는 장면을 살려줘.
- 조식·점심·저녁·카페·간식처럼 서로 다른 식사 사건은 실제 식탁이나 먹는 장면을 최소 하나씩 포함해줘.
- 대사가 없어도 장소의 분위기를 설명하는 풍경과 이동 컷은 적당히 포함해줘.
- 비슷한 장면과 흔들림이 심한 무의미한 구간은 반복하지 말아줘.
- 하루의 첫 장면과 마지막 장면이 여정의 시작과 끝처럼 느껴지게 해줘.
- 여행 중간이나 마지막에 가족이 한 명씩 여행 소감을 말하는 인터뷰가 있으면 완결된 답변으로 포함해줘.
- 콜드 오픈은 짧고 강하게, 본문은 너무 빠르지 않게 편집해줘.
